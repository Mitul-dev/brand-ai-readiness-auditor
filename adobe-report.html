Problem

Most crawled pages expose no navigation region

Evidence

0 of 13 crawled HTML pages contain a <nav> element or role="navigation"; the homepage exposes 22 internal links in total.

Navigation was detected structurally (nav landmark plus internal links inside it), so a visually styled menu that uses neither will also be reported here.

Metrics

{
  "pages_with_nav_landmark": 0,
  "pages": 13,
  "nav_share": 0.0,
  "home_internal_links": 22
}

Why it matters

Without a consistent navigation region, a visitor who lands on an interior page has no reliable way to move to the rest of the site, so the visit usually ends on the landing page.

Recommended fix

Provide a consistent primary navigation region on every page, marked up as a nav landmark.

  1. Wrap the primary menu in a <nav> element present on every template.
  2. Include links to the main sections (offering, pricing, about, contact).
  3. Make sure the links exist in the server-rendered HTML, not only after client-side hydration.
