Problem

robots.txt blocks 15 named AI or answer-engine crawler(s) from the entire site

Evidence

robots.txt contains a 'Disallow: /' group for: gptbot (OpenAI (training and retrieval)); oai-searchbot (OpenAI search); chatgpt-user (ChatGPT user-initiated fetch); claudebot (Anthropic); claude-user (Claude user-initiated fetch); claude-searchbot (Claude search); perplexitybot (Perplexity); perplexity-user (Perplexity user-initiated fetch). General crawling is not blocked, so these agents are singled out.

Why it matters

These are the crawlers that assistants and answer engines use to reach a site. While they are disallowed, the brand cannot be retrieved, quoted or cited by those systems no matter how good the on-page content is - third-party descriptions are used instead.

Recommended fix

Confirm whether this block is a deliberate content policy; if AI visibility is the goal, allow the agents you want to be discovered by.

  1. Decide per agent whether the goal is content protection or AI visibility - these pull in opposite directions.
  2. For agents you want to be discoverable in, remove the 'Disallow: /' from their group or narrow it to private paths.
  3. Keep training-only agents blocked separately from retrieval agents if you want citation without training use.
  4. Re-check robots.txt after deployment with each agent token.

F-003 · discoverability · stage: discover · priority medium · confidence 0.9

Problem

No XML sitemap was found

Evidence

Neither /sitemap.xml nor any Sitemap: directive in robots.txt returned a usable sitemap.

7 HTML pages were reachable by link following.

Metrics

{
  "sitemap_locations_tried": [
    "/sitemap.xml"
  ],
  "html_pages_crawled": 7
}

Why it matters

Without a sitemap, automated systems must rely entirely on link discovery, so pages that are weakly linked may never be reached.

Recommended fix

Publish an XML sitemap and reference it from robots.txt.

  1. Generate a sitemap listing canonical URLs of the public pages.
  2. Serve it at /sitemap.xml with HTTP 200 and content-type application/xml.
  3. Add a 'Sitemap: https://<host>/sitemap.xml' line to robots.txt.
